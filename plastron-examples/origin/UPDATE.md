# What's new — 2026-07-05

- 🐟 Formula-first fish docs — 10k Fish (boids10k) and boids are now sheets whose
  grid cells ARE the simulation: params, tables, =sysmap/=wrap systems, the pump
  config, and the =view() render pane all live in visible, editable cells.
- 📂 Open in the Sheets app — the workbook toolbar has a document picker over
  your stored sheets (with 🗑 delete; deletes confirm, never refuse).
- 🗔 Taskbar — the desktop tracks open / active / minimized windows along the bottom.
- 🧮 Collections algebra — one access algebra over dicts, lists, and ranges:
  .key, [0], slices, broadcasting.
- 💬 Chat — peer-to-peer chat over WebRTC. No servers, no stored keys.

"Refresh demo docs" reinstalls the shipped apps + demo documents to this build;
sheets and documents you created yourself are untouched.
